# v16：欧拉好猫哈曼车机强制全屏专版

基于用户指定的 v12，适用于 Android 8.1 / Intel x86、x86_64 的欧拉好猫哈曼车机。
包名 `com.shihab.diplay.ora81`，versionCode **45**，版本 `0.2.10-ora-android81-test16-fullscreen`。
沿用 v12 签名及欧拉返回车机图标；覆盖安装，无需卸载，音频和连接设置保留。

## 问题与修复

反馈照片中应用仅占左侧，右侧仍显示车机音乐面板。照片能确认窗口未铺满，
但不能单凭照片判定原车面板属于普通 Android 分屏还是厂商固定区域。
v12 的应用和活动声明可调整大小；进入多窗口后，还会主动显示系统栏。

v16 采用独立的好猫全屏应用配置：

- 应用及所有主要活动明确声明 `resizeableActivity=false`，阻止 Android 8.1 普通分屏。
- 设置宽屏最大比例为 4:1，覆盖好猫中控宽屏比例，避免关闭缩放后产生额外宽高比黑边。
- 首页、设置、CarPlay 及其他应用内页面请求沉浸式全屏，隐藏状态栏和导航栏。
- 页面创建、恢复前台和重新获得窗口焦点时恢复全屏；回调在销毁时移除。
- 旧的“显示系统栏”设置不会取消此专版的全屏策略；设置页明确标注强制全屏，并移除不再适用的小窗分辨率和系统栏开关。
- 保留 v12 的音乐/导航音道、Siri 导航音道、音频焦点、方向盘切歌、热点等待、图像比例和触控映射。

这是基于 v12 的显示专版，版本编号递增至 v16；不是从 v15 通用网络版衍生。
未修改无线连接协议、解码、认证或音频处理。原版 v12 安装包继续保留。

## 使用与验证

1. 安装 `Diplay-ORA-Android8.1-x86-v16-fullscreen.apk`，直接覆盖同签名版本。
2. 从车机应用列表重新打开 DiPlay，再连接 CarPlay；旧的桌面嵌入卡片可能由车机启动器继续限制尺寸。
3. 查看首页和 CarPlay 是否占满可用中控屏幕；切到车机桌面再返回后复查。
4. 检查方向盘切歌、音乐、导航和 Siri；原有音道与焦点设置保留。

本版按用户要求强制全屏，**不再使用普通分屏或车机小窗**。边缘滑动仍可临时呼出 Android 系统栏。
使用 Android 公开窗口接口，不依赖 root、系统签名、修改车机全局设置或伪装原厂包名。
厂商可覆盖标准窗口策略；若右侧面板由哈曼启动器固定占用，仍需进一步实车确认，不能宣称 APK 已能强制关闭所有原车面板。
Android 标准行为参考：[多窗口支持](https://developer.android.com/develop/ui/views/layout/support-multi-window-mode)。

自动测试覆盖 API 27 / 28 的全屏恢复、旧设置兼容和窗口销毁回调。
发布附件 `VALIDATION-v16.zip` 记录完整测试、lint、签名、原生库、v12 覆盖升级及 Android 8.1 模拟器窗口验证结果。
**本次全屏改动尚待真实好猫车机验证，以 Pre-release 发布；v12 的实车确认不等同于 v16 全屏已经实车验证。**
